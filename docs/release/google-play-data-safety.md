# Google Play Data Safety Declaration Form — CulinaryVerse AI

> **Target Application:** `com.culinaryverse.ai`  
> **Policy Source:** [Google Play Data Safety Form](https://support.google.com/googleplay/android-developer/answer/10787469)  
> **Account Deletion URL:** [https://culinaryverse.ai/privacy#account-deletion](https://culinaryverse.ai/privacy#account-deletion)

## 1. Data Collection & Sharing Overview

| Data Category | Collected | Shared with 3rd Parties | Stated Purpose | Optional? |
| :--- | :--- | :--- | :--- | :--- |
| **Personal Info > Name & Email** | Yes | No | App functionality (profile personalization, meal plan cloud synchronization). | Yes (User consent required) |
| **Audio > Voice Recordings** | Yes | No | App functionality (real-time voice command processing for cooking navigation). | Yes (User consent required) |
| **App Activity > In-App Interactions** | Yes | No | Analytics & personalization (saved recipes, dietary preference filters). | No |

## 2. Security Practices
- **Data Encrypted in Transit:** YES — All communications use TLS 1.3/HTTPS.
- **Data Deletion Mechanism:** YES — Users can request full profile and saved recipe deletion in-app or via `https://culinaryverse.ai/privacy#account-deletion`.
- **Children's Privacy:** App target audience is general public (13+). Does not knowingly collect data from children under 13.
